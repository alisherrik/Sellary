# Начало работы

## Что такое Sellary

Программа для магазина: касса, склад, закупки, клиенты, деньги и отчёты в одном
месте. Работает в браузере — устанавливать ничего не нужно. Для кассы есть
отдельное настольное приложение, которое продолжает работать без интернета —
см. [Приложение кассира](kassir-app.md).

---

## Вход {: #vkhod }

Вход состоит из двух шагов. Это не лишний экран: одна учётная запись может
работать в нескольких компаниях (магазинах), и программа должна знать, в какой
именно вы сейчас работаете.

**Шаг 1 — Вход**

1. Введите **имя пользователя** и **пароль**.
2. Нажмите **Продолжить**.

**Шаг 2 — Выбор компании**

1. Появится список компаний, к которым вы привязаны.
2. Нажмите на нужную → **Открыть рабочее пространство**.

Компания, отмеченная **По умолчанию**, предлагается первой.

!!! tip "Переключиться на другую компанию"
    Выйдите и войдите заново, выбрав другую компанию. Один сеанс работает
    с одной компанией — так исключено случайное действие «не в том магазине».

---

## Что вы увидите после входа

Слева — колонка разделов. Она у каждого своя: показываются только те разделы,
к которым вам открыт доступ.

| Раздел | Для чего |
|---|---|
| **Касса** | продажи и смена |
| **Продажи** | история чеков, возвраты, аннулирование |
| **Клиенты** | долги и история клиентов |
| **Склад** | товары, категории, списания |
| **Закупки** | поставщики, заказы, отчёт по закупкам |
| **Магазин** | заказы из Telegram-витрины |
| **Отчеты** | дашборд и аналитика |
| **Деньги** | счета, движения, переводы |
| **Настройки** | компания, сотрудники, доступы (только администратор) |

На телефоне разделы внизу экрана; те, что не поместились, — в кнопке **Ещё**.

## Роли и доступ {: #dostup }

Есть два уровня разграничения.

**Роль в компании**

- **Администратор** — видит всё, управляет сотрудниками и настройками.
- **Сотрудник** — видит только то, что ему открыли по модулям.

**Доступ к модулям** (для не-администраторов)

Каждому разделу можно дать один из двух уровней:

| Уровень | Что можно |
|---|---|
| **Сотрудник** | смотреть и выполнять обычную работу |
| **Менеджер** | дополнительно изменять: править товары, записывать движения денег, оформлять списания |

Пример настройки кассира: **Касса — Сотрудник**, **Продажи — Сотрудник**,
**Клиенты — Сотрудник**, остальное закрыто. Он продаёт, видит свои чеки и
долги клиентов, но не видит закупочных цен и отчётов.

Настраивается в [Настройки → Сотрудники](nastroyki.md#sotrudniki).

## Первые шаги в новом магазине

Порядок имеет значение — каждый шаг опирается на предыдущий.

1. **Настройки → Компания**: валюта и печать чека.
2. **Склад → Товары**: категории, затем товары (штрихкод, цены, остаток).
3. **Закупки → Поставщики**: у кого закупаетесь.
4. **Настройки → Сотрудники**: заведите кассиров и раздайте доступы.
5. **Деньги**: проверьте счёт «Касса» — сколько наличных в ящике сейчас.
6. **Касса → Смена**: откройте смену. Только после этого можно продавать.

## Проблемы со входом {: #problemy }

| Что видите | Что делать |
|---|---|
| **«Сервер недоступен»** | Нет связи с сервером. Проверьте интернет; вход будет заблокирован, пока связь не восстановится |
| **«Не удалось войти»** | Неверное имя пользователя или пароль |
| **Список компаний пуст** | Учётная запись не привязана ни к одной компании — обратитесь к администратору |
| **«Не удалось открыть эту компанию»** | Доступ к этой компании отключён |
| **Разделов меньше, чем было** | Изменили доступ к модулям. [Настройки → Сотрудники](nastroyki.md#moduli) |
| **Сотрудник не может войти** | Проверьте в Настройках: «Доступ разрешён» должен быть включён, учётная запись активна |

!!! warning "Пароль сотрудника"
    Пароль задаёт администратор при создании учётной записи и передаёт
    сотруднику лично. Программа не отправляет пароли на почту и не показывает
    их повторно.
