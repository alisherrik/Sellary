# Поставщики

Раздел **Закупки → Поставщики**. Справочник тех, у кого закупаетесь.

---

## Добавить поставщика

**Добавить поставщика** — форма:

| Поле | Обязательно |
|---|---|
| **Наименование** | **да** |
| Контактное лицо | нет |
| Телефон | нет |
| Email | нет |
| Адрес | нет |
| **Условия оплаты** | нет |

**Условия оплаты** — свободный текст: «Предоплата», «Оплата при доставке»,
«Отсрочка 30 дней». Это памятка для вас, программа по ней ничего не считает.

---

## Список

Колонки: **Наименование · Контакт · Телефон · Условия · Действия**.

Поиск — по названию и контактам. Фильтр: **С условиями / Без условий**.

Действия: **Редактировать**, **Удалить**.

---

## Зачем нужен поставщик

Поставщик участвует в трёх местах:

1. [Заказы поставщикам](zakazy.md) — заказ всегда оформляется на поставщика.
2. [Отчёт по закупкам](otchet.md) — вкладка «По поставщикам»: у кого сколько
   закупили.
3. [Списания](../sklad/spisaniya.md) — если товар вернули поставщику,
   указывается, кому.

---

## У поставщика нет баланса {: #net-balansa }

Программа **не ведёт взаиморасчёты с поставщиками**. Нет полей «мы должны» и
«переплатили», нет истории платежей поставщику.

Деньги, уплаченные поставщику, записываются на странице
[Деньги](../dengi.md) — **Изъять** с причиной **«Оплата поставщику»** и
комментарием, кому и за что.

По той же причине [возврат товара поставщику](../sklad/spisaniya.md#bez-deneg)
не создаёт никакого движения денег: уменьшать нечего.

!!! note "Почему так"
    Полноценный расчёт с поставщиками — это отдельный учёт: счета, акты,
    сверки, авансы. Половинчатая версия («поле с балансом») хуже, чем её
    отсутствие: цифра выглядит правдой, но ничем не подтверждена.

## Частые вопросы

**Можно ли удалить поставщика с историей закупок?**
Технически да, но лучше не надо: в старых заказах он перестанет отображаться.

**Один товар от нескольких поставщиков?**
Да, ограничений нет. В [отчёте по закупкам](otchet.md) будет видно, у кого и
почём брали.

**Где посмотреть, сколько мы должны поставщику?**
Программа этого не считает — см. выше.
