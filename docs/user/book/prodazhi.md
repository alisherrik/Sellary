# Продажи

Раздел **Продажи → История продаж**. Все чеки, возвраты и аннулирование.

---

## Список чеков

Колонки: **Время · Кассир · Позиций · Оплата · Сумма · Возврат · Статус**.

Фильтры: поиск, способ оплаты (Все оплаты / Наличные / Карта / Мобильный /
В долг), дата от и до.

### Статусы чека

| Статус | Значит | Что дальше |
|---|---|---|
| **Завершён** | обычная продажа | можно вернуть или аннулировать |
| **Частичный возврат** | часть товара вернули | можно вернуть остальное |
| **Возврат** | вернули всё | конечное состояние |
| **Аннулирован** | чек отменён целиком | конечное состояние |

### Статус оплаты (для чеков с долгом)

**Не оплачено** · **Частично оплачено** · **Оплачено**

## Сводка наверху

| Показатель | Что означает |
|---|---|
| **Оборот** | сумма чеков за выбранный период, с разбивкой по способам оплаты |
| **Чеков** | количество |
| **Средний чек** | оборот ÷ количество чеков |
| **Возвраты** | сколько вернули за период |
| **Оборот по часам** | в какие часы торгуют лучше |

!!! warning "Оборот — это не «сколько денег в кассе»"
    Оборот включает оплату картой и продажи в долг. Сколько наличных в
    ящике — на странице [Смена](kassa/smena.md), сколько денег всего — на
    странице [Деньги](dengi.md). Ссылки на обе стоят прямо в сводке.

## Карточка чека

Нажмите на строку — откроется чек: товары, подытог, налог, итого, способ
оплаты, история возвратов.

Кнопки: **Печать чека**, **Оформить возврат**, **Аннулировать**.

Если у чека есть долг, показывается блок **Долг клиента**: сумма, оплачено,
осталось, и кнопка **Принять оплату долга**.

---

## Возврат {: #vozvrat }

Покупатель принёс товар обратно.

1. Откройте чек → **Оформить возврат**.
2. Отметьте, что возвращают, и укажите количество по каждой строке.
   Программа показывает **Доступно: N** — сколько ещё можно вернуть.
3. Выберите **Способ возврата** — чем отдаёте деньги.
4. Укажите **Причину возврата**.
5. **Подтвердить возврат**.

Что произойдёт:

- товар вернётся на склад — в те же партии, из которых уходил;
- статус чека станет **Возврат** или **Частичный возврат**;
- деньги уйдут со счёта, которым вы возвращали.

### Возврат по чеку с долгом {: #vozvrat-i-dolg }

Если по чеку остался долг, программа покажет: **«Часть возврата спишется с
долга»**, и разложит сумму:

```
Возвращается товара на    50,00
Спишется с долга           4,00
Выдать деньгами           46,00
```

**Долг гасится первым.** Деньгами выдаётся только остаток.

!!! example "Почему именно так"
    Чек на 50: клиент заплатил 46 наличными, 4 остались в долг. Возвращает
    весь товар.

    Если списать долг **и** выдать 50, магазин отдаст на 4 больше, чем
    получил. Правильно: долг 4 обнуляется, на руки 46.

    Стоимость возвращённого товара при этом остаётся 50 — на неё уменьшается
    оборот.

### Частичный возврат

Возвращать можно частями, хоть по одной штуке. Каждый возврат уменьшает
«Доступно» по строке. Когда вернули всё — статус меняется на **Возврат**.

Программа следит, чтобы сумма частичных возвратов **точно** сошлась с тем, что
стоила строка: последний возврат по строке доплачивает копейки округления.

## Аннулирование {: #annulirovanie }

**Аннулировать** — отменить чек целиком, как будто продажи не было.

1. Откройте чек → **Аннулировать**.
2. Укажите **Причину аннулирования**.
3. **Подтвердить аннулирование**.

Результат:

- весь товар возвращается на склад;
- долг по чеку списывается полностью;
- чек исчезает из оборота и всех отчётов;
- **отменить нельзя** — это конечное состояние.

### Аннулирование одной позиции

Можно аннулировать отдельную строку чека — пробили не тот товар. Кнопка
**Аннулировать позицию** в карточке чека. Товар вернётся на склад, сумма чека
уменьшится.

### Возврат или аннулирование — что выбрать

| Ситуация | Действие |
|---|---|
| Покупатель принёс товар обратно | **Возврат** |
| Пробили не тот товар / ошибка кассира | **Аннулирование позиции** |
| Чек пробит целиком по ошибке | **Аннулирование** |
| Нужно вернуть часть товара | **Возврат** (частичный) |

Разница по существу: возврат — это событие торговли (товар был продан и
вернулся, оборот уменьшился), аннулирование — признание, что продажи не было.

---

## Оплата долга из чека

Кнопка **Принять оплату долга** в карточке чека делает то же, что оплата на
странице [Клиенты](klienty.md) — но сразу привязана к этому чеку.

Укажите сумму, способ (Наличные / Карта / Мобильный) и примечание.

## Частые вопросы

**Аннулировал по ошибке — как вернуть?**
Никак. Пробейте чек заново.

**Чек в закрытой смене — можно аннулировать?**
Нет. Итоги закрытой смены заморожены. Оформите возврат — он попадёт в текущую
смену.

**Возврат без чека?**
Не предусмотрено: программа возвращает товар в те партии, из которых он ушёл,
а без чека неизвестно, из каких.

**Почему в колонке «Оплата» написано «Наличные», а у клиента есть долг?**
Чек смешанный. В колонке показана **самая крупная** часть оплаты. Долг виден
в карточке клиента и в самом чеке.

**Сумма возвратов больше, чем выдали деньгами.**
Так и есть: часть возврата ушла на погашение долга и деньгами не выдавалась.
См. [Возврат и долг](cifry.md#vozvrat-i-dolg).
