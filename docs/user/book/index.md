# Быстрые ответы

Руководство по Sellary: касса, склад, закупки, деньги и отчёты. Каждая глава
устроена одинаково — **зачем это нужно → что нажимать → откуда берётся каждая
цифра → разбор случаев → частые ошибки**.

Не читайте подряд. Найдите свой вопрос ниже или воспользуйтесь поиском
(значок 🔍 наверху).

---

## Деньги не сходятся

| Вопрос | Ответ |
|---|---|
| **Почему «Ожидается в кассе» не совпадает с тем, что я насчитал?** | Разница называется **недостача** (насчитали меньше) или **излишек** (больше). Разбор всех причин — [Смена → Расхождение](kassa/smena.md#raskhozhdenie) |
| **Я насчитал правильно, а программа говорит «излишек» ровно на сумму карты** | В ящике лежат только **наличные**. Оплата картой ушла в банк, «в долг» ещё не получена. См. [Что в ящик не попадает](kassa/smena.md#chto-ne-popadaet) |
| **Откуда строка «Из прошлых смен»?** | Уточнения по уже закрытым сменам: деньги физически в ящике, но относятся к прошлому периоду. [Подробно](kassa/smena.md#iz-proshlykh-smen) |
| **Выручка на кассе и выручка в отчётах разные** | Это две разные величины: смена показывает **что прошло через кассу**, отчёты — **оборот за вычетом возвратов**. [Откуда берутся цифры](cifry.md#vyruchka) |
| **Клиент вернул товар, а долг не уменьшился на всю сумму** | Возврат сначала гасит долг, и только остаток выдаётся деньгами. [Возврат и долг](cifry.md#vozvrat-i-dolg) |
| **Где посмотреть, сколько всего денег у магазина?** | Страница [Деньги](dengi.md) — касса, банки и все счета вместе |

## Касса

| Вопрос | Ответ |
|---|---|
| **Не даёт продать: «Смена не открыта»** | [Откройте смену](kassa/smena.md#otkrytie) — без неё продажа не проходит |
| **Как принять оплату частями: часть наличными, часть картой?** | Способ оплаты → **Смешанная**. [Смешанная оплата](kassa/prodazha.md#smeshannaya) |
| **Как продать в долг?** | Способ оплаты → **В долг**, выберите клиента. [Продажа в долг](kassa/prodazha.md#v-dolg) |
| **Покупатель отошёл, а очередь стоит** | Откройте вторую вкладку чека. [Несколько чеков](kassa/prodazha.md#neskolko-chekov) |
| **Не даёт продать: «Недостаточно товара на складе»** | Остаток меньше, чем в корзине. [Почему нельзя продать в минус](kassa/prodazha.md#nelzya-v-minus) |
| **Нажал «Оплатить» дважды — спишется два раза?** | Нет. [Защита от двойной продажи](kassa/prodazha.md#dvoynaya-prodazha) |

## Если ответа здесь нет

1. Воспользуйтесь поиском наверху — он ищет по всему руководству.
2. Откройте главу нужного раздела: названия глав слева совпадают с
   названиями разделов в самой программе.
3. Раздел [Откуда берутся цифры](cifry.md) объясняет каждую формулу: выручку,
   прибыль, остаток кассы, долг.
