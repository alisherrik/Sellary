# Настройки

Раздел **Настройки**. Пять вкладок: Компания, Магазин, Сотрудники,
ИИ-коннектор, Система.

Вкладка **Сотрудники** видна только администратору компании. Вкладка
**ИИ-коннектор** — только если включён модуль «ИИ».

---

## Компания {: #kompaniya }

Реквизиты рабочего пространства: название, идентификатор, ваша роль,
состояние (Активна / Неактивна).

**Валюта** — используется в ценах, отчётах и чеках. Выберите и нажмите
«Сохранить».

**Печать чека** — печатать ли чек сразу после продажи.

- Включено — после каждой продажи чек уходит на печать.
- Выключено — ничего не печатается и денежный ящик не открывается.

Включайте, когда подключён принтер.

## Магазин {: #vitrina }

Как магазин выглядит в Telegram-маркетплейсе.

| Настройка | Что делает |
|---|---|
| **Включить маркетплейс** | пока выключено, покупатели магазин не видят |
| **Ссылка на логотип** | прямая ссылка на изображение для шапки магазина |
| **Описание магазина** | коротко о магазине |
| **Доставка** | курьер везёт заказ по адресу покупателя |
| **Самовывоз** | покупатель забирает заказ в магазине |

!!! warning "Хотя бы один способ получения обязателен"
    Если выключить и доставку, и самовывоз, покупатель не сможет оформить
    заказ. Программа предупредит.

Заказы приходят в раздел [Магазин](magazin.md).

## Сотрудники {: #sotrudniki }

Кто может входить в это рабочее пространство и на каком уровне.

### Добавить сотрудника

Два способа.

**Новый пользователь** — создать учётную запись с нуля:

| Поле | Примечание |
|---|---|
| Имя пользователя | по нему входят |
| Полное имя | как показывается в программе |
| Email | |
| **Пароль** | сотрудник войдёт с этим паролем — **передайте его лично** |
| Роль | Администратор / Сотрудник |
| Доступ разрешён | может ли входить |
| Компания по умолчанию | предлагать эту компанию первой |

**Существующий пользователь** — привязать к этой компании учётную запись,
которая уже есть в системе (человек работает в двух магазинах).

### Роль

| Роль | Что может |
|---|---|
| **Администратор** | всё, включая настройки и управление сотрудниками |
| **Сотрудник** | только то, что открыто по модулям |

### Доступ к модулям {: #moduli }

Для не-администраторов. По каждому модулю — один из двух уровней:

| Уровень | Что можно |
|---|---|
| **Сотрудник** | смотреть и выполнять обычную работу |
| **Менеджер** | дополнительно изменять |

Модули: **Касса · Продажи · Клиенты · Склад · Закупки · Магазин · Отчеты ·
Деньги**.

Что даёт уровень «Менеджер» на практике:

| Модуль | Сотрудник | Менеджер |
|---|---|---|
| Склад | смотреть товары | править товары, оформлять списания |
| Деньги | смотреть счета | внести, изъять, перевод, сверить |
| Касса | продавать, открывать и закрывать смену | то же |

!!! example "Типовая настройка кассира"
    **Касса — Сотрудник**, **Продажи — Сотрудник**, **Клиенты — Сотрудник**,
    остальное закрыто.

    Он продаёт, оформляет возвраты, видит долги клиентов. Не видит
    себестоимость, прибыль, закупочные цены и остатки на счетах.

!!! example "Типовая настройка управляющего"
    Все модули на уровне **Менеджер**, роль — Сотрудник. Управляет магазином,
    но не может заводить и удалять людей.

### Отключить доступ

Кнопка **Отключить доступ** — сотрудник не сможет войти в эту компанию, пока
доступ не вернут. Учётная запись при этом сохраняется вместе со всей историей.

!!! danger "Не отключайте доступ самому себе"
    Программа предупредит: «Это ваша учётная запись — вы потеряете доступ к
    этой компании».

## ИИ-коннектор {: #ai }

Подключение Claude и других ИИ-агентов к данным компании. Вкладка видна,
только если включён модуль «ИИ» — он не входит ни в один стандартный набор и
включается осознанно.

- **Адрес подключения** — скопируйте и вставьте в ИИ-приложение. Дальше оно
  само попросит войти и выбрать компанию.
- **Подключённые агенты** — кто сейчас имеет доступ, кто подключил и когда.
- **Отозвать** — закрыть доступ конкретному агенту.

!!! warning "Агент работает с вашими правами"
    Подключённый агент действует от имени того, кто его подключил, и с его
    правами. Отчёты он только читает. Единственное, что он может записать, —
    приход товара по закупке, и только после вашего подтверждения.

Подробная инструкция по подключению — в отдельном документе
`docs/MCP_CONNECTOR_GUIDE.md`.

## Частые вопросы

**Забыли пароль сотрудника.**
Задайте новый в карточке сотрудника и передайте лично. Восстановления по
почте нет.

**Сотрудник уволился.**
Отключите доступ. Не удаляйте учётную запись — на ней висит история продаж.

**Один человек работает в двух магазинах.**
Добавьте его как **Существующего пользователя** во вторую компанию. При входе
он будет выбирать, где работать.

**Изменил доступы — сотрудник не видит изменений.**
Ему нужно выйти и войти заново.
