# Продажа на кассе

Раздел **Касса → Касса**. Основной экран кассира: слева товары, справа корзина.

!!! danger "Без открытой смены продажа не пройдёт"
    Если внизу написано «Откройте смену, чтобы продавать» — сначала
    [откройте смену](smena.md#otkrytie). Это не формальность: смена — это
    промежуток, за который потом сходится касса.

---

## Как продать: коротко

1. Найдите товар — отсканируйте штрихкод или начните вводить название.
2. Нажмите на товар — он попадёт в корзину.
3. При необходимости измените количество или цену в корзине.
4. Нажмите **Оплатить**.
5. Выберите способ оплаты, введите сумму.
6. **Завершить продажу**.

Клавиша ++f2++ ставит курсор в поле штрихкода из любого места экрана.

---

## Поиск товара {: #poisk }

- **Штрихкод** — отсканируйте или введите вручную; товар добавится сразу.
- **Название** — начните вводить, список отфильтруется.
- **Фильтры**: наличие (Все товары / В наличии / Мало на складе / Нет в
  наличии), категория, цена от и до.

Что означают надписи на карточке товара:

| Надпись | Значение |
|---|---|
| **Мало на складе** | остаток ниже установленного уровня запаса |
| **Нет в наличии** | остаток 0 — товар нельзя добавить в корзину |
| **Весь доступный остаток уже в корзине** | добавить больше нечего |

---

## Корзина {: #korzina }

По каждой строке можно изменить:

- **Количество** — программа покажет «Доступно: N» и не даст превысить остаток.
- **Цену** — если продаёте по договорной цене. Изменение цены **действует
  только на эту строку этого чека** и не меняет карточку товара.
- **Сумму** — введите итог по строке, количество посчитается автоматически.
  Удобно для весового товара: «отпустите на 20 сомони».

Внизу корзины:

```
Подытог
Скидки на товары
Наценки на товары
Общая скидка
Общая наценка
Налог
Итого
```

Кнопка **Очистить корзину** удаляет все строки — программа переспросит.

## Несколько чеков одновременно {: #neskolko-chekov }

Покупатель ушёл искать кошелёк — не держите очередь.

1. Нажмите **Новая продажа** — откроется вторая вкладка чека.
2. Обслужите следующего покупателя.
3. Вернитесь к первой вкладке через **Активные продажи**.

Каждая вкладка хранит свою корзину. Оплачиваются они независимо. Вкладку можно
закрыть — программа предупредит, если в ней есть товары.

## Способы оплаты

### Наличные

Введите **Получено наличными** — программа посчитает **Сдачу**. Если получено
меньше итога, покажет **«Не хватает»** и не даст завершить продажу.

### Карта

Обязательно выберите **тип карты**: DC, Эсхата или Alif. Без банка продажа не
пройдёт — иначе потом невозможно понять, на какой счёт пришли деньги.

### Мобильный

Мобильный платёж. Деньги попадают на счёт «Банк (прочее)».

### В долг {: #v-dolg }

1. Способ оплаты → **В долг**.
2. Выберите **клиента** (обязательно) или создайте нового прямо здесь — нужны
   имя и телефон.
3. Если клиент платит часть сразу — заполните **Оплачено сейчас** и **Способ
   первого платежа**.
4. Программа покажет **Останется долг**.

Долг попадает в карточку клиента и погашается позже — см. [Клиенты](../klienty.md).

!!! warning "Первый платёж не может быть больше суммы продажи"
    Если пытаетесь ввести больше — это обычная продажа, а не долг.

### Смешанная {: #smeshannaya }

Один чек, несколько способов сразу. Например: 26 наличными + 10 картой DC +
10 картой Эсхата + 4 в долг.

1. Способ оплаты → **Смешанная**.
2. **Добавить способ оплаты** — по строке на каждый способ.
3. Для каждой строки укажите способ, банк (для карты) и сумму.

Программа показывает подсказку в реальном времени:

| Подсказка | Значение |
|---|---|
| **Осталось внести N** | сумма строк меньше итога |
| **Излишек N** | сумма строк больше итога |
| **Оплачено полностью** | можно завершать |

Правила:

- Сумма строк должна совпадать с итогом **точно, до копейки**.
- **Долг можно указать только один раз**.
- Для долга нужен клиент, для карты — банк.

## Завершение продажи

Нажмите **Завершить продажу**. Что произойдёт:

1. Создастся чек и его строки.
2. Товар спишется со склада по партиям (сначала тот, что куплен раньше).
3. Каждая часть оплаты запишется отдельно.
4. Если есть долг — появится запись в истории клиента.
5. Если включена печать чека — чек напечатается.

## Разбор случаев

### Почему нельзя продать в минус {: #nelzya-v-minus }

Сообщение **«Недостаточно товара на складе»** означает, что остатка меньше,
чем в корзине.

Продажа в минус запрещена намеренно: себестоимость берётся из партий прихода,
и партии, которой нет, не существует — программа не сможет сказать, сколько
этот товар стоил, и прибыль станет выдумкой.

Что делать:

- Уменьшите количество в корзине, **или**
- Примите товар через [Закупки](../zakupki/zakazy.md), **или**
- Если товар физически есть, а в программе нет — сделайте
  [корректировку остатка](../sklad/tovary.md#korrektirovka) и укажите причину.

!!! note "Исключение — приложение кассира"
    Настольное приложение кассира работает без интернета и в этот момент не
    может проверить остаток. Такие продажи принимаются как свершившийся факт,
    с пометкой. Подробнее: [Приложение кассира](../kassir-app.md).

### Нажал «Оплатить» дважды {: #dvoynaya-prodazha }

Двух чеков не будет. У каждой попытки оплаты свой ключ; если из-за плохой
связи запрос ушёл дважды, сервер узнает повтор и вернёт тот же чек.

Если после сбоя вы **изменили корзину**, появится сообщение «Корзина
изменилась после сбоя» — нажмите **Оплатить** ещё раз, это будет новая продажа.

### Цена этому покупателю другая

Измените цену прямо в строке корзины. Карточка товара не изменится, история
цены останется в чеке.

### Товара нет в списке

- Проверьте фильтр «Наличие» — возможно стоит «В наличии», а остаток нулевой.
- Проверьте, заведён ли товар: [Склад → Товары](../sklad/tovary.md).

## Частые ошибки

| Ошибка | Что происходит | Как правильно |
|---|---|---|
| Продать в долг без клиента | Продажа не пройдёт | Выберите или создайте клиента |
| Карта без выбора банка | Продажа не пройдёт | Укажите DC / Эсхата / Alif |
| В смешанной оплате две строки «В долг» | Продажа не пройдёт | Одна строка долга на чек |
| Изменить цену, думая что меняется товар | Меняется только этот чек | Цену товара правят в [Складе](../sklad/tovary.md) |
| Продавать без открытой смены | Продажа не пройдёт | [Откройте смену](smena.md#otkrytie) |
