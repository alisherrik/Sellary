# Клиенты

Раздел **Клиенты**. Кто и сколько должен магазину, и вся история по каждому.

---

## Список клиентов

Слева — список, справа — карточка выбранного клиента.

- **Поиск** по имени, телефону или email.
- **Фильтр по балансу**: Все · С долгом · Без долга.
- Справа от каждого клиента — его текущий долг.

---

## Карточка клиента

- **Текущий долг** — сколько клиент должен сейчас.
- **Принять оплату долга** — кнопка активна, только если долг больше нуля.
- **История долга** — все записи по клиенту.
- Карандаш вверху — исправить имя, телефон, описание.

!!! tip "Клиента, заведённого на кассе в спешке, можно поправить"
    Неверный телефон — не приговор. Нажмите карандаш в карточке.

---

## Откуда берётся долг {: #otkuda-dolg }

Долг появляется только одним способом: **продажа с частью «в долг»** на кассе.
См. [Продажа в долг](kassa/prodazha.md#v-dolg).

Долг = сумма всех записей в истории клиента:

| Запись | Знак | Когда появляется |
|---|---|---|
| **Продажа в долг** | + вся сумма чека | продажа с долгом |
| **Оплата при продаже** | − | заплатил сразу на кассе |
| **Оплата долга** | − | принёс деньги позже |
| **Возврат** | − | вернул товар |
| **Аннулирование** | − | чек аннулирован |

!!! example "Разбор одной продажи"
    Чек на 304, клиент отдал 100 сразу, 204 в долг.

    В истории появятся **две** записи:

    ```
    Продажа в долг #123      +304,00
    Оплата при продаже #123  −100,00
    ─────────────────────────────────
    Долг                      204,00
    ```

    Через три дня клиент принёс 204:

    ```
    Оплата долга             −204,00
    ─────────────────────────────────
    Долг                        0,00
    ```

    **Обратите внимание:** «Оплата при продаже» и «Оплата долга» — разные
    записи, хотя обе уменьшают долг. Первая — это деньги, уже посчитанные как
    оплата чека в тот день. Вторая — новые деньги, пришедшие позже. Считать
    их одинаково нельзя: одни и те же 204 попадут в отчёт дважды.

## Приём оплаты долга {: #oplata }

1. Выберите клиента.
2. **Принять оплату долга**.
3. Введите **Сумму оплаты**.
4. Выберите **Способ оплаты долга**: Наличные · Карта · Мобильный.
5. При необходимости — **Примечание**.
6. **Сохранить оплату**.

Что произойдёт:

- долг уменьшится на эту сумму;
- деньги придут на соответствующий счёт (наличные — в кассу);
- если смена открыта, сумма появится в блоке
  **«Прочие движения денег → Оплата долга»**.

### Как оплата распределяется между чеками

Если у клиента несколько неоплаченных чеков, оплата гасит их **по порядку, от
самого старого**. Например, долг 300 состоит из чеков на 100 и 200; клиент
принёс 150 — полностью погасится старый чек (100), и 50 уйдёт на новый.

!!! warning "Больше долга принять нельзя"
    Если ввести сумму больше текущего долга, программа откажет. Магазин не
    хранит переплату клиента — это была бы вторая, не связанная с этим,
    сущность.

## Разбор случаев

### Клиент вернул товар — что с долгом

Возврат сначала гасит долг по **этому же чеку**, и только остаток выдаётся
деньгами. Подробно: [Возврат и долг](prodazhi.md#vozvrat-i-dolg).

### Клиент вернул товар, а долг был по другому чеку

Возврат гасит долг только по своему чеку. Долг по другим чекам не трогается —
их нужно гасить оплатой.

### Клиент не платит

Программа не начисляет пени и не блокирует продажи должникам. Отфильтруйте
список по **С долгом** и обзванивайте.

### Клиент — оптовик, покупает регулярно в долг

Ничего специального не нужно: каждая продажа добавляет к балансу, каждая
оплата вычитает. История в карточке — полная выписка.

## Частые вопросы

**Можно ли завести клиента заранее, до продажи?**
Да — но отдельной кнопки «добавить» на этой странице нет: клиент создаётся на
кассе при продаже в долг. Проще один раз завести его на первой продаже.

**Можно ли удалить клиента?**
Нет. У клиента история покупок и долгов — удаление сделало бы прошлые чеки
непонятными.

**Долг отрицательный — что это?**
Клиенту вернули товара больше, чем он был должен. Проверьте историю: обычно
это возврат по чеку, который уже был оплачен.

**Где посмотреть, сколько всего должны магазину?**
Отфильтруйте список по **С долгом** — счётчик покажет количество. Общую сумму
долга по всем клиентам страница не считает.
