# Товары

Раздел **Склад → Товары**. Каталог, категории, остатки.

---

## Список товаров

Колонки: **Товар · Категория · Цена · Остаток · Уровень запаса · Маркетплейс**.

Поиск — по названию или штрихкоду. Слева — фильтр по категориям.

Метки на строке:

| Метка | Значит |
|---|---|
| **Мало** | остаток ниже уровня запаса |
| **Нет в наличии** | остаток 0 |

## Добавить товар {: #dobavit }

**Добавить товар** — откроется форма.

| Поле | Зачем | Обязательно |
|---|---|---|
| **Штрихкод** | сканирование на кассе | нет, но с ним быстрее |
| **Название** | поиск на кассе | **да** |
| **Категория** | группировка и фильтры | нет |
| **Единица измерения** | шт, кг, литр, упаковка | да |
| **Себестоимость** | закупочная цена — из неё считается прибыль | **да** |
| **Цена продажи** | по какой продаём | **да** |
| **Налог, %** | ставка по этому товару | нет (0 если не нужен) |
| **Количество** | текущий остаток | да |
| **Уровень запаса** | ниже него товар попадает в «Заканчиваются» | нет |
| **Описание** | для витрины магазина | нет |
| **Фото** | показывается покупателям в Telegram-витрине | нет |

!!! warning "Себестоимость — не косметическое поле"
    Из неё считается прибыль во всех отчётах. Товар с себестоимостью 0 даст
    прибыль, равную всей выручке, — то есть неправду.

    При этом себестоимость проданного берётся **из партии прихода**, а не из
    этого поля: поле задаёт цену только для первой, начальной партии. Дальше
    цену определяет приёмка закупки.

## Дополнительные единицы продажи {: #edinicy }

Один и тот же остаток можно продавать в разных единицах: штуками и упаковками,
граммами и килограммами.

1. В форме товара — блок **Дополнительные единицы продажи** → **Добавить**.
2. Укажите **Название** единицы (например, «Коробка»).
3. Укажите **Коэффициент** — сколько базовых единиц в одной такой.
4. Укажите **Цену** за эту единицу.

!!! example "Пример"
    Базовая единица — **шт**, остаток 240 шт.

    Дополнительная единица: **Коробка**, коэффициент **12**, цена 100.

    На кассе можно продать «2 коробки» — со склада уйдёт 24 шт, останется 216.
    Остаток один, просто продаётся по-разному.

Цена дополнительной единицы задаётся отдельно — она не обязана равняться
цене базовой единицы, умноженной на коэффициент. Так работает оптовая скидка
за упаковку.

## Корректировка остатка {: #korrektirovka }

Остаток в программе разошёлся с полкой — например, после инвентаризации.

1. Откройте товар → **Редактировать**.
2. Измените поле **Количество**.
3. **Сохранить**.

Программа запишет движение **«Корректировка остатка при редактировании
товара»** — с указанием, кто и когда его сделал.

!!! danger "Корректировка — не способ списать порчу"
    Если товар испортился, разбился или бракованный — оформляйте
    [Списание](spisaniya.md). Оно записывает **причину** и **себестоимость**,
    поэтому потом видно, сколько магазин потерял и на чём.

    Корректировка ничего этого не сохраняет: в отчётах останется просто
    «остаток стал другим».

Корректировка уместна, когда: пересчитали и нашли расхождение неизвестной
природы, исправляют старую ошибку ввода, заводят начальный остаток.

## История остатка {: #istoriya }

Кнопка **История остатка** в строке товара. Показывает каждое изменение:
что произошло, на сколько изменился остаток, кто это сделал и когда.

Причины движений: продажа, возврат, аннулирование, приёмка закупки, списание,
корректировка.

Это первое место, куда идти при вопросе «куда делся товар».

## Категории

Кнопка **Категории** → **Управление категориями**.

- **Добавить категорию** — название и краткое описание.
- Категорию можно править и удалять.
- Новая категория сразу появляется в форме товара.

Категории нужны для фильтра на кассе и в списке товаров, и для витрины
магазина.

---

## Публикация в маркетплейсе

Переключатель **Маркетплейс** в строке товара публикует товар в
Telegram-витрине. Покупателям видны название, описание, фото и цена.

Подробно: [Магазин](../magazin.md).

## Разбор случаев

### Товар пришёл дороже, чем был

Ничего менять руками не нужно. Примите
[закупку](../zakupki/zakazy.md#priemka) с новой ценой — программа создаст
новую партию по этой цене. Старый остаток продолжит продаваться по старой
себестоимости, пока не кончится.

### Нужно поднять цену продажи

**Редактировать** → **Цена продажи**. Изменение действует на будущие продажи;
прошлые чеки не меняются.

### Товар больше не продаём

Удалите его. Если товар участвовал в продажах, лучше просто убрать остаток в
ноль и снять с публикации — история чеков должна оставаться понятной.

### Один товар, два штрихкода

Не поддерживается: один товар — один штрихкод. Заведите второй товар или
используйте поиск по названию.

## Частые вопросы

**Почему нельзя продать товар, который лежит на полке?**
В программе его остаток 0. Сделайте корректировку или примите закупку.

**Изменил цену — изменились ли прошлые чеки?**
Нет. В чеке зафиксирована цена на момент продажи.

**Что такое «Уровень запаса»?**
Порог. Когда остаток падает ниже, товар попадает в «Заканчиваются» на
[Дашборде](../otchety/dashboard.md) и в «Мало на складе» на кассе.

**Можно ли загрузить товары списком из Excel?**
Нет, только по одному.
