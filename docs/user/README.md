# Документация для пользователей

Инструкции на русском языке, которые выдаются кассирам и управляющим магазина.
Файлы `.docx` собираются скриптами в `src/` — правьте скрипт, а не документ,
иначе следующая сборка затрёт правку.

| Документ | Кому | О чём |
|---|---|---|
| `Смена — руководство пользователя.docx` | кассир, управляющий | что такое смена, как открыть и закрыть, что означает каждая цифра на экране, разбор двух итогов (выручка и касса), внесения и изъятия, частые вопросы |
| `Почему карту не добавляют в кассу.docx` | кассир | почему в счёт наличных нельзя включать оплату картой; последняя страница — памятка для печати |
| `Деньги и закупки — руководство.docx` | владелец, управляющий | счета и движения денег (внести, изъять, перевод, сверить) и отчёт по закупкам: что купили, почём, у кого, и что заказано, но не пришло |

## Сборка

```bash
pip install python-docx
python docs/user/src/make_smena_doc.py     # SMENA_DOC_OUT=<путь к .docx>
python docs/user/src/make_card_doc.py      # CARD_DOC_OUT=<путь к .docx>
python docs/user/src/make_money_doc.py     # MONEY_DOC_OUT=<путь к .docx>
```

Оба скрипта берут путь вывода из переменной окружения и больше ничего от
среды не требуют — к базе они не обращаются.

## Разборы конкретных смен

Отчёты вида «Смена №N — разбор выручки» строятся по данным работающей базы и
содержат имена покупателей и суммы их долгов, поэтому в репозиторий не
коммитятся (см. `.gitignore` в этом каталоге). Генератор такого отчёта —
одноразовый: он читает `DATABASE_PUBLIC_URL` и печатает разбор одной смены.
